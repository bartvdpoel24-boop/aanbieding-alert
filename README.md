# AanbiedingAlert

Webapp om boodschappen te volgen die je **alleen in de aanbieding** wilt kopen. Stel een prijsdrempel in en krijg een seintje als de prijs daaronder komt.

Prijzen komen van [PrijsProfeet](https://www.prijsprofeet.nl) (AH, Jumbo, Lidl, Aldi, PLUS, Dirk en meer). Je lijst blijft in de browser.

## Gebruik

- Voeg een product toe, of tik een suggestie.
- **Grok stelt een prijs voor** op basis van de huidige aanbiedingen.
- Check één product of alles. Onder je drempel zie je **Koop nu**.
- Bij openen checkt de app zelf als de vorige ronde meer dan 20 uur geleden is.
- Onder **Deals** volg je een korting met één tik.
- Meldingen zet je aan via **Info**.

## Lokaal draaien

```bash
npm install
npm run dev
```

De app luistert op poort 8080.
